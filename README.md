# Game Sandbox

A personal repository for testing game development mechanics across different languages.

## Games

### Cube Coin Collector
*   **Language:** Rust (built with `macroquad` and `rand`)
*   **Goal:** Control a cube to collect 10 randomly spawning coins.

### Battleship
*   **Language:** Python
*   **Goal:** A turn-based strategy game utilizing a dynamic 2D grid rendering system.

## Setup & Execution

### Prerequisites
*   Python 3.x
*   Rust and Cargo toolchain

### Running the Projects
Clone the repository, navigate to the respective directory, and run the command:

*   **Battleship (Python):** `python battleship.py`
*   **Cube Coin Collector (Rust):** `cargo run`
